# LEXORA

**Learn English. Live the Language.**

منصة ألعاب تفاعلية لتعلّم اللغة الإنجليزية من المستوى المبتدئ إلى المتقدم.

## الألعاب الحالية
- صيد المفردات
- ترتيب الحروف وتكوين الكلمات
- بناء الجمل
- الاستماع والتمييز السمعي
- المحادثات اليومية
- تحديات المستوى المتقدم

التقدم والنقاط محفوظة محلياً على الجهاز في هذه النسخة التجريبية.
