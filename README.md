# LEXORA — Starter Website

A responsive Arabic-first landing page prototype for LEXORA, an English-learning platform.

## Files
- `index.html` — landing page and demo account modal
- `style.css` — responsive visual design
- `app.js` — language toggle and demo interactions

## Deploy
This is a static website. Set the deployment build command to empty and the output directory to the repository root (`/`) when connecting it to a static hosting project.

## Important prototype limitations
This repository currently contains a frontend demonstration only. Login, Google OAuth, account creation, payments, subscriptions, course access control, saved progress, dictionary, real video playback, admin dashboard, and database persistence are not implemented. Demo forms intentionally do not send or store credentials. Do not enter real passwords in this prototype.

## Product decisions reflected here
- Arabic and English interface direction toggle
- FREE and PRO concept; PRO price displayed as 5 JOD/month
- Original realistic American-English learning scenes are planned
- Learning path: Foundation, A1, A2, B1, B2, C1
- Dark navy and mint visual identity
